---
name: prevent-test-modification
description: Use this skill to ensure that test files remain unaltered during code modifications.
---
- Always create new test files for additional tests instead of modifying existing ones.
- Review the test directory structure to confirm no original test files are changed.
- Implement version control practices to track changes in test files.
- Use automated checks to verify that no test files have been modified before committing changes.
- Document any new tests added in a changelog or comments for clarity.
