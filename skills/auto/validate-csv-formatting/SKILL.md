---
name: validate-csv-formatting
description: Use this skill to ensure CSV files adhere to specified formatting rules.
---
- Confirm that the CSV header matches the required format and includes all necessary columns.
- Validate that all data entries conform to the expected types (e.g., integers for IDs, floats for amounts).
- Check for consistent date formatting (e.g., YYYY-MM-DDTHH:MM:SSZ) across all date fields.
- Ensure that there are no duplicate rows based on unique identifiers (e.g., order IDs).
- Implement automated tests to verify CSV formatting before processing or analysis.
